# Tuần 4 — Bài tập: Luồng điều khiển

## Cơ bản

In bảng cửu chương của một số bằng vòng lặp `for`.

- **Đạt:** In đúng 1–10, dùng `range` đúng.

## Nâng cao

Cho danh sách điểm, dùng comprehension tạo nhãn đạt/không đạt, rồi `zip` in "tên — điểm — nhãn".

- **Đạt:** Comprehension và `zip` dùng đúng, kết quả đúng.

## Thử thách

Tìm tất cả số nguyên tố dưới 100 chỉ dùng `for`/`if`/`range`.

- **Đạt:** Thuật toán đúng, không dùng thư viện, code rõ ràng.

## Rubric (100 điểm)

| Tiêu chí | Điểm |
|---|---:|
| Đúng chức năng | 35 |
| Xử lý lỗi/an toàn (thụt lề, tránh vòng lặp vô hạn) | 25 |
| Chất lượng code/tài liệu | 20 |
| Phân tích/giải thích | 20 |
