# Tuần 5 — Bài tập: Chuỗi & văn bản + trực quan dữ liệu

## Cơ bản

Dùng f-string in bảng thông tin 3 sinh viên; vẽ biểu đồ điểm của họ.

- **Đạt:** f-string đúng, biểu đồ có nhãn và tiêu đề.

## Nâng cao

Đọc file text local, đếm tần suất 5 từ phổ biến nhất và vẽ biểu đồ cột.

- **Đạt:** Đọc file bằng `with`, đếm đúng, biểu đồ cột rõ ràng.

## Thử thách

Vẽ 2 biểu đồ con: đường của hàm bậc hai và histogram của 1000 số ngẫu nhiên.

- **Đạt:** Subplot đúng, histogram dùng NumPy, nhãn đầy đủ.
