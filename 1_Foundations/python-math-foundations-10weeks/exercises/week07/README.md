# Tuần 7 — Bài tập: PyTorch căn bản

## Cơ bản

Tạo tensor 3×2, in shape/dtype, đổi thành 2×3 rồi trải phẳng.

- **Đạt:** shape/dtype đúng, reshape đúng.

## Nâng cao

Viết lớp `Dataset` giả chứa `features` và `labels` (tensor), có phương thức trả số mẫu.

- **Đạt:** Class đúng, thuộc tính tensor, phương thức trả `len`.

## Thử thách

Sinh tensor 1000 số ngẫu nhiên có seed, tính trung bình/độ lệch chuẩn bằng PyTorch, so với giá trị kỳ vọng.

- **Đạt:** Seed tái lập, thống kê đúng, nhận xét được sai lệch.
