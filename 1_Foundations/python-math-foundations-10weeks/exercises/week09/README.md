# Tuần 9 — Bài tập: Gradient descent

## Cơ bản

Chạy GD 1D cho $f(x)=(x-3)^2$; in số epoch cần để `x` gần 3.

- **Đạt:** Công thức cập nhật đúng, hội tụ về 3.

## Nâng cao

Vẽ đồ thị giá trị hàm theo epoch cho 3 learning rate khác nhau trên cùng một hình.

- **Đạt:** 3 đường rõ ràng, phân biệt hội tụ nhanh/chậm/phân kỳ.

## Thử thách

Cài đặt GD 2D cho hàm có local minimum (ví dụ $f(x,y)=\sin x + y^2$), khảo sát ảnh hưởng điểm khởi tạo.

- **Đạt:** GD 2D đúng, nhận xét được vai trò điểm khởi tạo.
