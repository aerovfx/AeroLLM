# Lịch 10 tuần / 10-Week Schedule

[← Tổng quan](INDEX.md) · [Đồ án](projects/final_project.md)

Mỗi tuần một buổi 120 phút: 30 phút lý thuyết, 60 phút lab/code review, 30 phút kiểm tra và phản tư.

| Tuần | Chủ đề | Lý thuyết chính | Lab | Mốc nộp |
|---:|---|---|---|---|
| 1 | Google Colab & môi trường Python | Notebook, cell, runtime, môi trường | Tạo notebook, chạy ô code/text, kiểm tra môi trường | Ảnh notebook + script hello |
| 2 | Kiểu dữ liệu Python | int/float/str/bool, list, dict, toán tử | Khai báo biến, tính toán, cấu trúc dữ liệu | Script data types |
| 3 | Hàm | def, tham số, return, scope, help | Viết hàm, truyền tham số, NumPy random | Script hàm |
| 4 | Luồng điều khiển | for, if-else, comprehension, enumerate/zip | Vòng lặp, nhánh, xử lý danh sách | Script luồng điều khiển |
| 5 | Chuỗi & trực quan dữ liệu | f-string, xử lý text, matplotlib | Xử lý văn bản local + vẽ biểu đồ | Script chuỗi + biểu đồ |
| 6 | Indexing & slicing | chỉ mục âm, slicing, step | Cắt danh sách/chuỗi, mảng NumPy | Script indexing/slicing |
| 7 | PyTorch căn bản | class, tensor, dtype, shape, reshape | Tạo tensor, đổi shape, random | Script tensor |
| 8 | Toán cho deep learning | dot product, ma trận, softmax, entropy | Tính toán vector/ma trận bằng NumPy | Script toán |
| 9 | Gradient descent | đạo hàm, LR, epochs, local minima | GD 1D/2D, so sánh LR | Script GD |
| 10 | Bản chất mạng nơ-ron | perceptron, forward, loss, backprop | ANN nhỏ trong PyTorch | Capstone mini |

Chi tiết mục tiêu, lab, câu hỏi và rubric nằm trong `lessons/weekNN.md`. Code mẫu nằm trong `code/weekNN/`, bài tập trong `exercises/weekNN/README.md`.
