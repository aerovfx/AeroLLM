# Bài tập tuần 07 — Fine-tuning open-weight

Bài tập chính nằm trong [bài học tuần 07](../../lessons/week07.md), gồm 3 mức:

- **Cơ bản**: thao tác và kiến thức cốt lõi của tuần.
- **Nâng cao**: kết hợp ít nhất hai khái niệm.
- **Thử thách**: tình huống mở, nhiều cách giải.

Nộp theo yêu cầu trong bài học, kèm bằng chứng chạy (log hoặc ảnh kết quả).
