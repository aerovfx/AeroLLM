# Đồ án — Open-Weight Specialist / Capstone — Open-Weight Specialist

[← Tổng quan](../INDEX.md) · [Lịch học](../schedule.md)

## Đề bài / Brief

Fine-tune một instruct model open-weight bằng QLoRA cho một task có thể đánh giá: structured output, classification có giải thích, domain assistant, style hoặc code transformation. Phải có baseline, held-out test và artifact chạy lại được.

## Deliverables

Project/task brief; model/license decision; dataset card và QA; notebook/script SFT; adapter config; before/after evaluation; error/safety analysis; adapter hoặc export; model card và inference instructions.

## Rubric 100 điểm

| Hạng mục | Điểm |
|---|---:|
| Task, baseline, method choice | 10 |
| Data quality, rights, split | 20 |
| QLoRA/SFT đúng và tái lập | 20 |
| Evaluation/error analysis | 25 |
| Export/deployment verification | 10 |
| Model card, safety, presentation | 15 |

## Gates

Không lộ credential; có quyền dùng data/model; test không vào train; artifact nạp được; metric sau export được kiểm tra; kết luận không vượt quá bằng chứng.
