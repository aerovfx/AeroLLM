# Lịch 10 tuần, 20 buổi / 10-Week, 20-Session Schedule

[← Tổng quan](INDEX.md) · [Đồ án](projects/final_project.md)

| Tuần | Buổi 1 | Buổi 2 | Mốc nộp |
|---:|---|---|---|
| 1 | Fine-tune vs RAG/prompt/CPT | Task brief, baseline, success metrics | Baseline pack |
| 2 | Instruct/base, model cards, license | VRAM/precision/context capacity lab | Model decision record |
| 3 | Data contracts, provenance, split | Cleaning, dedup, PII, human QA | Dataset card v1 |
| 4 | ChatML/ShareGPT/Alpaca | Template rendering, labels, token audit | Formatted dataset |
| 5 | LoRA math/target modules | QLoRA config, trainable params, smoke test | Adapter config |
| 6 | SFTTrainer và effective batch | LR/epoch/context ablation, logging | Training run |
| 7 | Task/quality/safety metrics | Blind review, error taxonomy, regressions | Eval report |
| 8 | Preference data và DPO objective | DPO experiment và KL/regression audit | Preference report |
| 9 | Adapter/merge/GGUF/vLLM | Clean-session inference, latency/quality | Deployable artifact |
| 10 | Model card, risk and release | Demo, peer audit, retrospective | Final package |

Mỗi tuần có hai buổi 90–120 phút; chi tiết trong `lessons/`.
