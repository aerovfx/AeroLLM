# Lịch 10 tuần, 20 buổi / 10-week, 20-session schedule

[Trang khoá học](INDEX.md)

Mỗi tuần gồm một buổi 90 phút về khái niệm/report và một buổi 120 phút lab/review.

| Tuần | Buổi A — theory/report | Buổi B — lab/review | Deliverable |
|---:|---|---|---|
| 1 | Claim–evidence–limitation | Scale và feasibility | claim ledger |
| 2 | KDA recurrence + Gated MLA | Toy KDA, numerical checks | unit tests |
| 3 | Full/Block AttnRes | Depth mixer toy | ablation memo |
| 4 | LatentMoE, SiTU-GLU, QB | Balanced routing | routing dashboard |
| 5 | Text/vision mixture, Muon | Dataset card | data plan |
| 6 | Progressive long context | Cache/parallelism design | systems memo |
| 7 | SFT, partial-rollout RL, MOPD | Effort budget simulator | RL plan |
| 8 | White-box harness, AET | Verifier-first agent task | environment package |
| 9 | MXFP4/MXFP8 QAT, draft model | Benchmark audit | evaluation card |
| 10 | Integration | Demo, defense, peer review | capstone |
