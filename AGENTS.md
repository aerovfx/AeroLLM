# Repository instructions

## AeroLLM course work

Khi yêu cầu liên quan đến tạo khóa học mới, tạo hoặc sửa bài học theo tuần, sinh code minh họa, thêm chú thích code, tạo bài tập/rubric/final project, chuẩn hóa điều hướng hay code viewer, phải đọc và làm theo toàn bộ skill:

`skills/cyberlearn-course-creator/SKILL.md`

Khi skill dẫn tới `references/course-blueprint.md`, chỉ đọc reference đó nếu nhiệm vụ cần tạo nhiều file, thiết kế lộ trình hoặc rubric.

Yêu cầu cụ thể của người dùng luôn có ưu tiên cao hơn mặc định trong skill.
