# Chạy trên Google Colab

1. Tải [`mini_gpt_walkthrough.ipynb`](../notebooks/mini_gpt_walkthrough.ipynb) lên Colab.
2. Chọn **Runtime → Change runtime type → T4 GPU** nếu muốn thử model lớn hơn; notebook mặc định chạy được bằng CPU.
3. Chạy **Runtime → Run all**. Không đổi kích thước model trước khi cell Checks đạt.
4. Lưu bản sao vào Drive và ghi runtime/GPU/seed trong báo cáo.

Nếu copy `mini_gpt_lab.py`, đặt file trong cùng thư mục notebook hoặc upload bằng Files panel. Không lưu token/credential trong notebook.
