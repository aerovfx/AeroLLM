# Lịch 10 tuần, 20 buổi / 10-Week, 20-Session Schedule

[← Tổng quan](INDEX.md) · [Đồ án](projects/final_project.md)

Mỗi buổi 90 phút: 25 phút lý thuyết, 50 phút lab/code review, 15 phút kiểm tra và phản tư.

| Tuần | Buổi 1 | Buổi 2 | Mốc nộp |
|---:|---|---|---|
| 1 | LM, next-token objective, baseline | Repository tour, tensor contract, tests | Baseline card |
| 2 | Character/BPE tokenization | Binary data, split, DataLoader | Tokenizer report |
| 3 | Token/position embeddings | Context windows, batching, shape tests | Embedding notebook |
| 4 | Q/K/V và scaled dot-product | Causal mask, softmax, invariance test | Attention test suite |
| 5 | Heads, concat, projection | Vectorization và efficiency | MHA module |
| 6 | MLP/GELU | LayerNorm, residual, pre-norm | Transformer Block |
| 7 | GPT config/model assembly | Parameter count, forward/loss tests | Integrated mini-GPT |
| 8 | AdamW, schedule, clipping | Training loop, eval, checkpoints | Reproducible run |
| 9 | Temperature/top-k/top-p | Evaluation, error analysis, benchmark | Sampling report |
| 10 | Capstone hardening/model card | Demo, peer review, safety retrospective | Final package |

Chi tiết từng buổi, discussion và rubric nằm trong `lessons/weekXX.md`.
