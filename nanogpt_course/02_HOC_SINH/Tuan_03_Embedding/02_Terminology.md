# Tuần 3: Embedding & Position — Terminology

| Thuật ngữ Tiếng Việt | Thuật ngữ Tiếng Anh | Phiên âm (IPA) | Định nghĩa & Ý nghĩa ngắn gọn |
| :--- | :--- | :--- | :--- |
| **Không gian nhúng** | Embedding Space | /ɪmˈbɛd.ɪŋ speɪs/ | Không gian vector nhiều chiều nơi các từ được biểu diễn dưới dạng tọa độ để thể hiện ngữ nghĩa. |
| **Bảng tra cứu nhúng** | Embedding Lookup | /ɪmˈbɛd.ɪŋ ˈlʊk.aʊt/ | Hành động truy xuất vector đại diện cho một Token ID từ bảng trọng số học được. |
| **Nhúng vị trí** | Position Embedding | /pəˈzɪʃ.ən ɪmˈbɛd.ɪŋ/ | Vector cộng thêm vào Token Embedding để cho mô hình biết vị trí của token đó đứng thứ mấy trong câu. |
| **Độ tương đồng Cosine** | Cosine Similarity | /ˈkoʊ.saɪn ˌsɪm.əˈlær.ə.t̬i/ | Phép toán đo góc giữa hai vector để xác định mức độ gần gũi về nghĩa giữa các từ. |
